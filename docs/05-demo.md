# 5. Demo con datos de prueba 

## Montar una demo desde el IOMAD dashboard

Usar **solo datos inventados**:

1. Hacer una **instantánea** de la máquina antes de tocar nada.
2. Configurar el **cron** (ver [Producción](03-produccion.md)) y comprobarlo.
3. Crear 2 empresas, con 2 o 3 departamentos cada una.
4. Un gestor por empresa y algunos usuarios de prueba (`alumno1@example.com`, `alumno2@example.com`...).
5. Un curso común a todas las empresas y otro privado de una de ellas.
6. Probar la **carga masiva por CSV** con el fichero de ejemplo que ofrece la propia pantalla de importación de usuarios.
7. Anotar qué funciona y qué no.
